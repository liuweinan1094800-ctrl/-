简易键盘连按器｜Simple Key Repeater
软件介绍｜About
专为游戏中的重复按键操作设计。如果你只是想让某个按键自动连按，不想折腾按键精灵等软件的脚本、录制和复杂设置，这款小工具就够了。

选择按键 → 设置速度 → 按快捷键开始。
无需编写脚本，无需安装，解压即可使用。

Designed for repeated key presses in games. If you only need to press one key repeatedly without dealing with scripts, recordings, or complicated macro software, this tool keeps things simple.

Choose a key → Set the speed → Press a hotkey to start.
No scripting or installation required. Just extract and run.
主要功能｜Features
- 自选连按键：支持字母、数字、空格、回车、方向键等。
  Selectable keys: Letters, numbers, Space, Enter, arrow keys, and more.
- 速度可调：每秒 1–50 次，默认每秒 10 次。
  Adjustable speed: 1–50 presses per second; default is 10.
- 快捷键可修改：默认 F1 开始 / 暂停、F2 停止，可设置为 F1–F11。
  Customizable hotkeys: F1 to start/pause and F2 to stop by default. Choose from F1–F11.
- 立即开始，持续运行：没有倒计时，切换窗口不会自动停止。
  Instant, continuous operation: No countdown. Switching windows does not stop the repeater.
- 轻量简洁：不联网、不安装服务、不记录键盘输入。
  Lightweight and simple: No network connection, service installation, or keystroke logging.
使用方法｜How to Use
1. 解压文件，双击 KeyRepeater.exe。
   Extract the files and double-click KeyRepeater.exe.
2. 选择需要连按的按键，设置每秒次数。
   Choose the key to repeat and set the presses per second.
3. 根据需要修改开始 / 暂停和停止快捷键。
   Customize the start/pause and stop hotkeys if needed.
4. 切换到游戏窗口，按开始快捷键即可运行。
   Switch to your game and press the start hotkey.
5. 再按一次开始快捷键暂停，或按停止快捷键结束。
   Press the start hotkey again to pause, or use the stop hotkey to stop.
使用说明｜Notes
- 按键发送到当前获得焦点的窗口。 切换窗口后，会向新窗口继续发送按键，并非锁定后台游戏。
  Key presses go to the currently focused window. After switching windows, input goes to the new window—not to a game running in the background.
- 快捷键不能重复，也不能与连按键相同。修改设置前，请先停止。设置仅在本次运行中有效。
  Hotkeys must be different from each other and from the repeated key. Stop before changing settings. Settings apply only to the current session.
- 每秒次数为目标速度，实际响应取决于系统和游戏。建议先用每秒 5–10 次测试。
  The selected speed is a target rate. Actual response depends on your system and game. Start by testing at 5–10 presses per second.
- 如果游戏以管理员身份运行，连按器也需要以相同权限运行。部分游戏可能不接受模拟输入。
  If the game runs as administrator, run this tool with the same privileges. Some games may not accept simulated input.
- 适用于 Windows 10 / 11 64 位。请遵守所使用游戏的自动操作规则。
  For 64-bit Windows 10 / 11. Follow your game's rules on automated input.
